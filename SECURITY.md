# Security Policy

## Supported versions

This repository is an alpha technical preview. Security fixes target the
latest commit on the default branch.

## Reporting a vulnerability

Do not open a public issue containing credentials, private infrastructure
details, or an exploitable vulnerability. Use GitHub's private vulnerability
reporting feature when it is enabled for the repository. Otherwise, contact
the repository owner privately through their GitHub profile.

## Public artifact policy

Never commit model weights, access tokens, passwords, internal terminal URLs,
private hostnames, user-specific mount paths, or raw logs that may contain
request data. Hardware verdicts should retain only the minimum environment and
result metadata needed to reproduce the claim.
